# Planning output

Return:

1. the business outcome;
2. assumptions that materially affect ownership;
3. the recommended app, Module, and Service shape;
4. a dependency direction diagram or compact list;
5. the first useful slice;
6. a table with capability, owner, authoritative data, public surfaces,
   collaborations, and reason for the boundary;
7. verification and Console evidence; and
8. the next authoring skill.

Ask clarifying questions only when a missing answer changes ownership, trust,
or the first slice. Otherwise state a conservative assumption and continue.
