# Autonomous Service verification

Prove the exact supported combination, stable Service identity, Workload
registration, Store ownership and migrations, Contract compatibility, context
propagation, and health or reliability evidence.

Run the first useful workflow plus a relevant Failure Scenario such as timeout,
duplicate delivery, crash-window recovery, dependency outage, or Store restart.
Verify observed behavior, durable checkpoints, operator evidence, and cleanup
against the declared outcome.

For production delivery work, report immutable artifact identities, policy and
eligibility evidence, the reviewable deployment plan, and the Approval Boundary.
Repository access and passing checks do not authorize deployment.
